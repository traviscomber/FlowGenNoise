# FlowSketch — Historical Spatial Media & Generative Art Work

This repository is an **original N3uralia creative-technology project** exploring generative visual systems for cultural, panoramic and immersive formats.

It is preserved as part of the engineering history that informed the current creative verticals:

- **[N3uralia360](https://n3uralia360.art)** — immersive & spatial media;
- **[VisionCraft](https://v1sioncraft.art)** — AI motion and structure-preserving visual workflows.

This repository is historical implementation evidence, not the canonical description of either current product.

---

## What FlowSketch explored

FlowSketch combined generative-image workflows with projection-aware creative formats, including:

- cultural and heritage-oriented visual generation;
- standard image compositions;
- 360° / equirectangular concepts;
- stereographic and spherical treatments;
- fulldome / hemispherical projection concepts;
- prompt structuring and scenario systems;
- image enhancement and post-processing;
- reusable visual presets for creative production.

The important engineering question was not simply how to generate an image, but how to generate visual material for a **specific spatial surface and viewing geometry**.

## Product lineage

```text
Generative visual experiments
          ↓
Projection-aware image formats
          ↓
360° / dome / heritage workflows
          ↓
Spatial + motion production systems
       ↙                 ↘
N3uralia360          VisionCraft
```

This work helped establish several themes that remain relevant in the current creative portfolio:

1. **Format is part of the generation problem.** A dome, panorama and flat frame are not interchangeable outputs.
2. **Cultural material needs provenance and restraint.** Generative systems should support interpretation without presenting invented detail as historical evidence.
3. **Creative pipelines need controllability.** Prompts, projection constraints, enhancement and output preparation should be explicit stages rather than hidden model behavior.
4. **The source and artistic intent remain important.** Later N3uralia visual systems increasingly prioritize preservation and structure over unconstrained regeneration.
